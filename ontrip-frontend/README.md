# OnTrip — Frontend Application 🎨📱

This directory contains the client-side single page web application (SPA) for **OnTrip**, built with **React 19** and **Vite**.

For full project documentation, architecture diagrams, and system overview, please refer to the main [Root README.md](../README.md).

---

## ⚡ Tech Stack

- **Framework**: React 19 + Vite 7
- **Routing**: React Router DOM v7
- **Real-Time Communication**: Socket.io-client
- **Interactive Maps**: Leaflet
- **Document Generation**: HTML2Canvas & jsPDF / html2pdf.js
- **Payments**: Razorpay Checkout SDK

---

## 🚀 Development Scripts

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build
```
