# OnTrip — Backend API Server ⚡⚙️

This directory contains the server-side REST API and WebSocket server for **OnTrip**, built with **Node.js** and **Express 5**.

For full project documentation, architecture diagrams, and system overview, please refer to the main [Root README.md](../README.md).

---

## ⚡ Tech Stack & Integrations

- **Server Framework**: Express.js (v5)
- **Database & ORM**: MongoDB Atlas + Mongoose
- **Real-Time Engine**: Socket.io
- **AI Models**: Google Gemini AI (`@google/genai`) & OpenAI API
- **Cron Scheduler**: Node-Cron
- **Payments Engine**: Razorpay Node SDK
- **File Uploads**: Cloudinary + Multer
- **Emails**: Brevo (Nodemailer)

---

## 🚀 Development Scripts

```bash
# Install dependencies
npm install

# Run dev server with nodemon
npm run dev

# Start server in production
npm start
```
